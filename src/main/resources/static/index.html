¿Cómo se instala?

Chrome o Edge: descomprimí el zip, abrí chrome://extensions, activá Modo de desarrollador y elegí Cargar descomprimida con la carpeta.

Firefox: abrí about:debugging#/runtime/this-firefox y elegí Cargar complemento temporal con el zip. Firefox la quita al cerrarse.
