# ADR-0006: `404` único para enlaces vencidos e inexistentes

- **Estado:** Propuesta (🟡 pendiente de confirmar en grupo, R2; a validar con el Cliente, Q5)
- **Fecha:** 09/10/2026
- **Referencias:** `contexto.md` D7, D20, R2, C6

## Contexto
El Cliente pidió que un alias vencido muestre una página informativa con un camino para crear un enlace nuevo (C6). Con borrado físico (ADR-0002), una fila vencida termina desapareciendo.

## Decisión
- Vencido o inexistente responden **`404`** con la misma página (`enlace-no-disponible.html`): "Este enlace expiró o no existe" y un botón para crear un enlace nuevo.
- Un enlace vigente responde `302 Found`, nunca `301` (un 301 queda en la caché del navegador y seguiría redirigiendo después del vencimiento).

## Alternativas descartadas
- **`410 Gone` para vencidos** (Martín y Agustín): exige recordar qué alias existieron, lo que contradice el borrado físico.

## Consecuencias
- Contrato simple: el cliente no necesita distinguir los dos casos.
- Si se pasa a archivar (ADR-0002 revisado), `410` vuelve a ser posible.
